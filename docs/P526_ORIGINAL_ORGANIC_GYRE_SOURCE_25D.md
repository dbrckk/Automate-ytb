# P5.26 — Stop drawing a circular chart over the original ocean

## Actual decoded-video defect
An inspected **real 30.0667-second 1080×1920, 30fps Kokoro H.264/AAC
Short** generated by P5.25 still showed an obvious perfect blue circular
plate during the Coriolis scene. The rest of the ocean story also contains
scientific labels and arrows, but the circular central chart stood out as
an artificial presentation object. Increasing global sharpening is not a
valid fix for the original flat source geometry.

## Source geometry, not postprocessing
`automate_ytb.flow_material25d.vortex_source` now paints one irregular
connected **translucent organic water mass** instead of an opaque circular
presentation disc. The actual alpha mask follows four deterministic
seeded, scale-separated angular contour harmonics. A wide differentiable
rim fades the surface into the surrounding originally authored ocean.
A more irregular, high-frequency fine material field adds locally
coherent surface light without frame RNG. The pre-existing 12 independently
animated swirl arms remain; 23 additional fine water-shear streamlines
follow and deform along the same original current geometry.

The source cache is shared by `ocean`, `lagoon`, and `storm` palettes.
No download, stock image, AI generation, 3D, GPU, paid API, source
hallucination, inaccurate location claim or unnecessary new dependency.
Native science overlays remain stationary and untouched, and fluid paths
still move continuously rather than changing as still slides.

## Reproducible verification
`scripts/review_vortex_organic25d.py` uses **two actual repository
checkouts**, one immutable CI baseline at current `main` and one PR
checkout. It executes the same production `PortraitScienceScene` Python
renderer at the same narration, timestamp and 1080×1920 resolution for
both, and also saves both actual source RGBA masks. The script fails when
the original geometry is not modified, text-safe zones change or the
real water subject is lost. Full-size source PNGs, a before/after contact
sheet, per-file SHA256 hashes and elapsed CPU timing form the Actions
artifact.

Unit tests verify irregular soft edges and absence of a circular plate,
transparent alpha, 3 real shared material palettes, exact same-time
determinism and moving 9:16 source frames. Existing `test_flow_material25d`
and `test_science_storyboards` stay active, along with the full production
suite and the existing Kokoro/H.264 narrated real-video gate. Both
source-screen technical success and human aesthetic review are required.

This is only the **source vortex asset** upgrade. Other data-explainer
primitives (diagram arrows, temporary labels, simplified landmasses,
character anatomy, narrative scene coverage) remain separate targets
for the next complete source-asset pass. We do not claim the finished
films have reached AAA quality.

# Real owned footage in original cross-genre videos

## What this enables

Documentary, cinematic, product, interview and personal montage scenes can now
contain **real moving video** rather than just photographs with Ken Burns.
The shared production pipeline accepts local MP4, MOV, MKV and WEBM footage
subject to media probing, explicit commercial rights evidence and approval.

Each scene may use either:

- A reviewed still image, automatically animated by the directed camera path.
- A reviewed real video clip (trimmed, standardized to H.264, 30fps video-only).
- An existing specialized original 2D/Blender animated rig, unchanged.

These approaches can coexist in a single storyline. Each scene still occupies
its exact original time interval and shares the existing captions, narration,
transitions, soundtrack and publish-review controls.

## One local command for footage

First prepare an original scene plan using the existing scene planner. Then:

    python -m automate_ytb.production ingest-video \
      --plan build/scene-plan.json \
      --scene scene-001 \
      --video /path/to/your-original-footage.mp4 \
      --provider my-camera \
      --rights-note "I filmed this and own the commercial editing rights." \
      --confirm-rights

Optionally select a segment with --start-seconds 12.5. Use --replace only
when deliberately overwriting an existing scene. This command copies a trimmed
normalized MP4 into assets/scene-001.mp4 and extracts a genuine poster to
assets/scene-001.png. A manifest retains both SHA256 digests and the original
codec, duration and trim; no video is generated by AI.

    python -m automate_ytb.production audit \
      --plan build/scene-plan.json
    python -m automate_ytb.production render \
      --plan build/scene-plan.json \
      --output build/finished-video \
      --resolution 1080p --fps 30

For a mixed project, import every other scene as either an approved image or
approved video. The old still-image command remains supported.

## Safety and production rules

- Input must be a real local file with a supported video extension; no remote
  URL or network downloader, unsafe path, symbolic link or injected shell.
- Source capped at 250 MiB, duration capped at two hours, decoded video bounds
  and scene trim validated. Source may be up to 4096px in either dimension.
- Normalization creates offline H.264/yuv420p at 30fps, up to 1920px per
  dimension. The output is selected to the scene duration and does not repeat
  or secretly freeze frames to fill a short source clip.
- **Camera audio is intentionally removed** to prevent unauthorized or
  incoherent sound layering. The authored narration and original music still
  use the existing EBU R128 mastering path.
- Rights declaration is mandatory. The normalized video and its generated
  thumbnail are SHA256-verified at audit and again before preview rendering.
  Changing either blocks the render.
- The source footage is never sent to external inference APIs or published
  to YouTube. Full editorial and publication review is still required.

## Current limits

This is a real, usable footage path, not automatic multi-camera editing.
Audio from original footage is deliberately not mixed. Video content selection,
semantic cuts, stabilization, face/product-aware reframing, voice-genre
direction and mobile upload UI are future work. Large original videos may
require preprocessing or scene selection. Android-only users can run this
through a hosted or connected workflow once the upload interface is provided.

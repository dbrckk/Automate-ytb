# Original character motion review (Android)

The **Original character motion review** GitHub Actions workflow produces
a contact sheet from four actual short H.264 MP4s generated by the
production rigs. It runs automatically after changes to original animation
code on the default branch, and can be started manually from Actions.

## Where to find the result on Android

1. Open the GitHub repository and select **Actions**.
2. Open **Original character motion review**, then the latest successful run.
3. Download the **original-motion-review** artifact (ZIP).
4. Open **motion-gallery.png**: four columns are actual moments in the
   same encoded clip; each row tests a different character and action.
5. Play any file in **motion-clips/** to judge continuity, motion arcs,
   transitions, pose quality, and visual clarity at 24 frames per second.
6. Read **motion-gallery.json** for frame count and successive sampled
   frame differences, primarily to catch unexpectedly frozen animation.

The original showcase covers a fox jumping in a forest, a running rabbit
in a meadow, a talking cat in a nighttime village, and a flying owl over a
river. These are fixed authored test scenes, not copied YouTube stories.

Everything uses the same Pillow/FFmpeg pipeline, original authored artwork
and the free GitHub runner; no ElevenLabs account, paid image model, external
assets or publication credentials are needed. GitHub-hosted workflow minutes
and artifact retention depend on the repository/account billing settings.

**Important:** A successful render or non-zero pixel motion does not prove
premium visual quality. These artifacts expose defects for human review,
rather than automatically awarding an AAA grade.

Run on a local computer if desired:

    python scripts/render_motion_gallery.py --output out/motion-gallery.png

For a fast single-character check:

    python scripts/render_motion_gallery.py --actor fox --output out/motion-gallery.png

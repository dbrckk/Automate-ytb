# P5.6 — eliminate generic slideshow framing from the real 2.5D workflow

## User product requirement

All future generated original video imagery remains **2.5D only**,
and the **reusable production workflow** must improve across subjects.
A one-off lightning visual is not an implementation of this requirement.

## Observed source-video failures after P5.5

Downloaded actual main-branch preview artifacts (2026-11-09), extracted
five time-separated frames per topic, and inspected the decoded contact sheet:
- Rainbow: all five scenes used rigid title/picture/caption cards;
  sampled visual QA itself flagged paired large panels in 5/5 scenes.
- Volcano: fewer dominant cards, but 3/5 sampled scenes lacked fine detail.
- Forest: independent near/far landscape, moving character and caption
  already read as a continuous 2.5D world, without the slide layout.

These are observations, not a claim that image quality is already extreme.

## Implemented reusable production changes

- Original science renderer uses one common source-safe **open 2.5D editorial**
  system rather than subject-by-subject top and bottom boxed overlays.
- Feathered alpha luminance is bounded to header/caption safe regions;
  source world remains full resolution and physically animated; no 3D assets,
  static slides, synthetic zoom-on-photo, fake video or AI imagery.
- All chapter captions use the exact pre-existing audio phrase cues and
  `_fit_lines` layout. No transcription or cue time is fabricated.
- Minimal unilateral typographic accent and restrained chapter indicator
  retain readable scene context without double full-height frame rails.
- Original scene-plan style defaults no longer ask for 3D illustrations.
  The planner remains a **brief**, not an unimplemented render generator.
- Cross-topic evidence generated by running the **actual**
  PortraitScienceScene renderer for rainbow, volcano and ocean, with
  original high-resolution PNGs and a visual contact sheet.

## Not yet solved

Many domain renderers still draw simplistic source geometry (rainbow rays in
a coordinate diagram, volcano triangulated mountain, etc.). This is not
automatically improved by removing text cards. P5.7 must author richer
multi-layer silhouettes, terrain, atmospheric effects and material/lighting
atlases for each semantic object family **through shared primitives**.

## Mandatory safeguards

Pass fast multi-topic visual and caption tests, full production suite and
specialized video previews. Actually review the contact sheet to verify no
disappearing captions, inset text clipping or loss of explanatory geometry.
No merge on a red check. No social publishing without human editorial review.
